# 사람인 직무코드(job_cd) 조사 — 미확정

> 2026-08-12 조사. **확정된 값이 아닙니다.** access-key 발급 후 실제 응답으로 검증해야 합니다.
> 출처: https://oapi.saramin.co.kr/guide/code-table5?mcode=2 (IT개발·데이터)

## 1. ★ 코드 체계가 두 갈래입니다 — 확인 필요

코드표 한 페이지 안에 **자릿수가 다른 두 계열**이 섞여 있습니다.

| 계열 | 예 | 추정 |
|:--|:--|:--|
| **4자리 `22xx`** | 2248 데이터 사이언티스트, 2246 BI 엔지니어, 2247 개발PM, 2229 SQA, 2232 풀스택 | 앞 두 자리가 `22`. 기획안이 확정한 `job_mid_cd=22`(IT개발·데이터)와 일치 → **이쪽이 `job_cd`일 가능성이 높음** |
| **2~3자리** | 181 AI(인공지능), 109 머신러닝, 108 딥러닝, 133 컴퓨터비전, 160 NLP, 272 Python, 248 Pandas | Python·Pandas·React 같은 **기술 키워드**가 섞여 있음 → `job_cd`가 아니라 별도 키워드 코드일 수 있음 |

또 하나 걸리는 점: 코드표 페이지의 URL 파라미터는 `mcode=2`인데 기획안이 확정한 `job_mid_cd`는 `22`입니다. **`mcode`는 페이지 탭 번호이고 `job_mid_cd`와 다른 값일 가능성**이 큽니다(4자리 코드가 전부 `22`로 시작하는 것이 근거). 다만 추정입니다.

**결론: 지금 `job_cd`를 하드코딩하지 마세요.**

## 2. 검증 절차 (access-key 발급 직후 최우선)

M5 착수 전에 이 3회 호출로 확정합니다. 일 500회 한도에서 3회면 무시할 수준입니다.

```
① job_mid_cd=22 만 지정, job_cd 없이 호출
   → total 값과 응답의 job-code 필드 확인. 여기 찍힌 코드가 진짜 job_cd입니다
② ①의 응답에서 관측된 코드 중 하나로 job_cd 지정 후 호출
   → 결과가 좁혀지면 4자리 계열이 정답
③ job_cd=181 (2~3자리 계열) 로 호출
   → 에러 3(유효하지 않은 param)이면 이 계열은 job_cd가 아님
```

**③이 핵심입니다.** 에러 3이 나오면 2~3자리 계열은 버리고, 안 나오면 두 계열 다 쓸 수 있습니다.

## 4. 신뢰도

이 표는 **페이지를 자동으로 읽어 추출한 것이라 누락·오독 가능성이 있습니다.** 전체 항목이 320개 규모인데 그중 일부만 뽑았습니다. `job_cd`를 채우기 전에 브라우저로 페이지를 직접 열어 대조하세요.
