## 선정 근거

1. **저가 티어 성능 1위 평** (Artificial Analysis 인용 보도, 웹 확인). GPQA Diamond
   92%급 이해력 — 검증자는 요약의 왜곡을 잡는 역할이라 이해력이 재현율을 결정합니다.
2. **strict JSON 지원.** 검증자 출력은 `Verdict` 스키마로 파싱되므로 JSON 안정성이
   파이프라인 안정성입니다. 파싱 실패 = 그날 검증 불능.
3. **비용은 이 규모에서 무의미합니다.** 하루 검증 ~7건(요약 5 + 재생성), 건당
   입력 ~2K/출력 ~0.5K 토큰이면 정가 기준 건당 $0.001 — **90일 전체 $1 미만.**
   따라서 가격이 아니라 신뢰성으로 골랐습니다.
4. 차점 탈락 사유:
   - Gemini Flash-Lite 계열: 2.5 세대가 **2026-10-16 은퇴 예고** — 90일 운영
     한가운데에 걸립니다. 3.x Lite로 시작하는 것도 가능하나 Luna 대비 이점 없음
   - DeepSeek V4 Flash: 최저가지만 **베이징 업무시간대 2배 시간제 요금**이
     원장 `cost_usd`의 일관성을 해칩니다. 폴백으로만

## 주의사항

- **OpenRouter 슬러그는 호출 직전 재확인.** 위 ID는 2026-08-16 조사 기준이며
  프로바이더 라우팅·이름이 바뀔 수 있습니다.
- **프로모 가격(현재 50% 할인, $0.10/$0.60)으로 예산을 잡지 마세요.** 정가 기준으로
  계산하고, 실측은 원장 `cost_usd`로 누적합니다.
- 이 결정은 **잠정 확정**입니다. M2 DoD가 최종 판정합니다 — 왜곡 샘플 3건
  (`tests/fixtures/distorted_summaries.yaml`)을 모두 잡고 정상 요약(대조군)을
  통과시켜야 확정. 실패하면 폴백과 교차 실측 후 이 문서를 `_1`로 갱신하세요.
- 벤치마크의 한계: GPQA·HLE는 "문제를 푸는" 능력이지 "왜곡을 잡는" 능력이 아닙니다.
  그래서 최종 판정이 벤치마크가 아니라 자체 왜곡 샘플인 것입니다.
