## 1. 재사용 규칙 — 이것부터 지키세요

기계적으로 따르세요. 각 항목에 **어기면 무엇이 조용히 망가지는지**를 붙였습니다.

| # | 규칙 | 어기면 조용히 망가지는 것 |
|:--:|:--|:--|
| R1 | 프로파일은 **반드시** `src.core.config.load_profile("profile.papers")` 로 읽는다. 경로를 문자열로 쓰지 않는다 | `profile.papers_2.yaml`이 생기는 순간 구버전을 읽는다. 테스트는 통과하고 결과만 틀린다 |
| R2 | arXiv HTTP 요청은 **반드시** `SingleConnectionRateLimiter.slot()` 컨텍스트 **안에서만** 연다 | 슬롯 밖에서 열면 `test_arxiv_single_connection`은 여전히 통과하는데(그 테스트는 슬롯을 직접 씀) 실제 운영에서 동시 커넥션이 열려 IP 차단 |
| R3 | 원장은 `ledger.RunRecord` + `ledger.append()` 로만 쓴다. `json.dumps`를 직접 하지 않는다 | 키 순서와 `schema` 값이 어긋나 기존 2줄과 비교 불가. 기획안 §12 가동률이 거짓이 됨 |
| R4 | 요약 검증 대상 필드는 `schema.VERIFIABLE_FIELDS` 를 import 해서 쓴다. `("problem","method",...)` 를 다시 타이핑하지 않는다 | `connection`이 채점에 들어가 **모든 요약이 감점**된다. 지표 자체가 무의미해짐 |

### 2.8 `src/verify/`

```python
# gates.py
class GateViolation(RuntimeError)
class ScopeViolation(GateViolation)

def model_family(model_id: str) -> str
def assert_verifier_differs(generator_model: str, verifier_model: str) -> None
```

`model_family` 인식 계열 7개: `anthropic|claude` / `openai|gpt-|o[1-9]-` / `google|gemini|gemma` / `meta|llama` / `mistral|mixtral` / `qwen` / `deepseek`. 못 알아보면 ID 전체가 계열.
★ ID 비교가 아니라 **계열 비교**입니다. `claude-opus-5` ↔ `claude-haiku-4-5`는 **거부**됩니다.
`assert_faithfulness_flagged`는 임계 미달 자체를 막지 않습니다. **플래그 누락만** 막습니다.

```python
# faithfulness.py
_BARE_INT_MIN = 100     # ★ 교차언어 오탐 하한선

@runtime_checkable
class Verifier(Protocol):
    model_id: str
    def verify(self, abstract: str, summary: PaperSummary) -> Verdict: ...

class RuleBasedFakeVerifier:
    model_id = "rulebased_fake/v1"
    def __init__(self, penalty_per_claim: float = 0.35)
    def verify(self, abstract: str, summary: PaperSummary) -> Verdict
```

수치 대조 규칙: 요약 쪽은 **소수 / 백분율 / 100 이상**만 검사. 연도(`19xx|20xx`)는 제외. `36.0`과 `36`은 같게 봅니다.
잡는 것 = ① 수치 조작뿐. **② 인과 조작 ③ 한계 반전은 못 잡는 것이 설계**입니다 — 규칙으로 흉내 내면 하한선 베이스라인 자격을 잃습니다.
**LLM 검증자를 만들 때는 이 Protocol(`model_id` + `verify`)을 그대로 만족시키세요.** 그러면 테스트 하네스를 고칠 필요가 없습니다.
