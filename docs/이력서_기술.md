  코드로 차단해 자기선호 편향을 구조적으로 배제
- 법적·재현성 제약(API 약관, 라이선스, 키 유출)을 pytest 게이트 18종으로 강제 — 실패 시
  파이프라인이 빨간불로 멈춤

## C. 상세 버전 (포트폴리오·자기소개서)

**Radar — 논문·채용공고 개인화 선별 파이프라인** (개인 프로젝트, 2026.08~)
`Python 3.11 · sentence-transformers · SQLite · GitHub Actions · Hugo`
github.com/EuijeongHan/dream-radar

**선별을 검색 문제로 정의하고 정량 평가**
- arXiv 일 700여 건 → 2단계 랭킹(bge-m3 임베딩 top-30 → bge-reranker-v2-m3 top-5)
- 관심사 15개를 **가중 최대**로 합성. 가중 평균은 독립 관심사 15개에서 14개의 낮은 유사도가
  신호를 지운다고 판단, 두 방식을 비교 조건으로 함께 측정
- 평가: Hit@5 / MRR / nDCG@10 — 키워드 매칭 베이스라인 대비 `[ ]% → [ ]%`
- 교차언어 손실 실측: 동일 관심사의 영어/한국어 프로파일로 랭킹 비교 `[ ]`

**생성자·검증자 분리 검증 게이트**
- 요약 생성(Claude)과 faithfulness 채점(GPT-5.6 Luna)을 **다른 계열**로 분리.
  모델 ID 비교로는 부족해(같은 계열의 다른 크기 모델이 통과) **계열 단위**로 차단
- 임계 0.7 미달 시 미근거 주장을 프롬프트에 주입해 재생성(최대 2회), 이후에도 미달이면
  경고 플래그와 함께 발행하고 원장에 기록 — **미달을 숨기지 않고 기록**
- 의도적 왜곡 3종(수치 조작·없는 인과·한계 반전) 샘플로 검증자 적발률 측정 `[ ]`

**측정 가능한 운영 설계**
- 실행 원장(`runs.jsonl`) 6줄에 수집 2,765건·신규 1,851건 기록. **게이트 실패 2건도 지우지
  않고 보존** — 실패를 지우면 가동률 수치가 거짓이 됨
- 아이템 2단계 수명주기(collected → published)로 발행 실패 시 하루치 유실 방지
- pytest 455개 / 법적·재현성 게이트 18종

**법적 제약을 코드로 강제**
- arXiv 3초·단일 커넥션 제약을 파일락으로 강제(슬립 루프로는 동시 커넥션을 못 막음).
  락으로 막을 수 없는 머신 간 중복은 한계로 명시하고 운영 규칙으로 분리
- 채용공고는 약관상 공개 게시 불가 → 소스 어댑터가 `publish_scope="private"` 를 리터럴로
  고정하고 공개 싱크가 재검사. 설정 수정으로 우회 불가
- 적대 검토에서 **봇 토큰이 공개 원장으로 유출되는 경로**를 발견·차단하고 회귀 테스트 추가
