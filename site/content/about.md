Radar는 매일 아침 읽을거리를 고르는 일을 자동화한 개인 파이프라인입니다.
arXiv에 새로 올라온 논문 수백 건을 수집해 관심사 프로파일과 대조하고,
그중 5편을 골라 요약과 함께 이 사이트에 게시합니다.

## 파이프라인

```
수집 → 중복제거 → 1차 랭킹(임베딩) → 2차 랭킹(리랭커) → 요약 → 검증 → 발행 → 피드백
```

- **수집**: arXiv API로 신규 논문의 제목·초록(서술 메타데이터, CC0)만 가져옵니다.
  전문(PDF)은 다운로드하거나 저장하지 않습니다.
- **랭킹**: 관심사 프로파일을 질의로 삼아 임베딩 유사도로 후보를 추리고,
  크로스인코더 리랭커로 최종 5편을 선별합니다.
- **요약·검증**: 생성 모델이 쓴 요약을 **다른 계열의 모델**이 초록과 대조해
  왜곡 여부를 채점하고, 기준 미달이면 재생성합니다.
- **피드백**: 읽음/스킵 기록이 프로파일 가중치로 환류됩니다.

## 이 프로젝트가 지향하는 것

수집·요약·발행만 하는 봇은 이미 많습니다. 이 프로젝트의 관심은 두 가지입니다.

1. **선별을 검색 문제로 정의하고 정량 평가합니다.** 직접 라벨링한 골드셋으로
   Hit@5 / MRR / nDCG@10을 재고, 키워드 매칭 베이스라인 대비 개선폭을 수치로 남깁니다.
2. **생성과 검증을 분리합니다.** 요약 생성자와 검증자를 서로 다른 계열의 모델로
   강제해 동일가족 편향을 피하고, 검증 점수와 재생성률을 실행 원장에 기록합니다.

평가 결과표는 정리되는 대로 이 사이트에 공개할 예정입니다.

## 채널

논문 채널의 선별 결과만 이 사이트에 게시합니다.
채용공고 채널은 비공개 채널로만 전달됩니다.
